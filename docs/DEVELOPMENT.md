# Experiment 001: design and development record

## Human direction
Build a personal portfolio inspired by Rockstar Games. Store in jtwray/portfolio-experiments and use a feature branch for every new reference. Include evidence of software development and AI-assisted / human-in-the-loop SDLC.

## Design interpretation
Black publisher-style navigation, a large split feature, commanding condensed typography, amber interactions, a browsable project catalog and editorial project details. Original Blue Ridge artwork grounds the experience in Asheville rather than borrowing game imagery. Project cards become inspectable case files. Project filters make the catalog usable, not merely decorative.

## Human / AI boundary
Human supplied intent, reference and repository. AI inspected the public reference and GitHub evidence, designed and implemented the interface, and performed available checks. Final aesthetic approval and career claim confirmation belong to the human and remain pending. No claims of past professional AI deployments, measured productivity gains or certifications are made.

## Decisions
- No framework for a static portfolio: zero runtime dependencies and portable deployment.
- Native HTML dialog provides modal focus and Escape handling.
- No invented employers, education credentials, metrics, reviews or project outcomes.
- Branch codex/rockstar-portfolio isolates this experiment.
- Content sources and verification limits are tracked alongside source.

## Review prompts
Does this feel like you? Which project deserves a deeper case study? What precise responsibilities and outcomes can you substantiate? Those answers can refine the next iteration without changing the source-based claims here.

## Baymard selection context
The human selected Rockstar from Baymard's award list. Verified 2026-10-30: https://baymard.com/ux-benchmark/case-studies/rockstargames lists UX Award Winner, Video Games (Mobile), Top 1%. The evaluated URL is store.rockstargames.com, first benchmarked June 2025. The original visual reference is rockstargames.com. These are distinct scopes. Premium scoring and annotated recommendations are gated; no claim of access to those is made. This portfolio is not Baymard-rated.

Transfer to portfolio: clear navigation; readable project descriptions; category filters with selected state; generous mobile tap targets; one-column mobile browsing; accessible project details; visible next actions. Validate these properties rather than assuming that visual similarity inherits a UX score.
