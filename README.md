# Portfolio Experiments

A collection of Tucker Wray portfolio UI/UX experiments. Each inspiration gets its own feature branch; experiments do not replace one another.

## Experiment 001 — Built to Explore
- Inspiration: https://www.rockstargames.com/
- Branch: `codex/rockstar-portfolio`
- Implementation: dependency-free HTML, CSS, JavaScript; original SVG and CSS artwork.
- Run: `npm run dev` then open http://127.0.0.1:4173
- Check: `npm run check`
- Static deployment directory: `dist`

Project filters, keyboard-accessible case study dialogs, responsive navigation, source links, and email contact are functional. No API credentials are required. Google Fonts is optional; system fallbacks apply offline.
